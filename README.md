# 我的课表（金皓天 · 2026-2027 学年第 1 学期）

首页是「今日卡片」，主界面是「周课表网格」，配色是柔和马卡龙色。
课表内容来自教务系统打印稿，节次时间用浙江工商大学下沙校区的上课时间表。

## 怎么打开

电脑上：**双击 `index.html`**，什么都不用装（不用 Node、不用 Python、不用联网）。
手机上：看下面「装到 OPPO 手机上」。

## 我的课表里现在有什么

- **10 门课、22 条排课**（同一门课不同周次、不同教室分开记录）
- 课程：应用技术、电路与装置（含实验）、中级羽毛球、马克思主义基本原理、毛泽东思想和中国特色社会主义理论体系概论、工程学术英语 1、工程数学 1A、大学生职业发展规划、形势与政策(6)、创业基础实训(理)
- 第 1 周周一 = **2026-09-14**（教务处通知：9 月 14 日起全校正式上课，教学周 16 周），所以 9 月 23 日是**第 2 周**
- 节次时间（下沙校区，每节课 45 分钟）：

| 节次 | 时间 | 节次 | 时间 |
| --- | --- | --- | --- |
| 1 | 08:05-08:50 | 7 | 14:35-15:20 |
| 2 | 08:50-09:35 | 8 | 15:30-16:15 |
| 3 | 09:50-10:35 | 9 | 16:25-17:10 |
| 4 | 10:40-11:25 | 10 | 18:30-19:15 |
| 5 | 11:30-12:15 | 11 | 19:25-20:10 |
| 6 | 13:40-14:25 | 12 | 20:20-21:05 |

课表里带 **◇** 的是实验课（虚线边框），带周次角标的是非全周课程（比如「9-11周」），
同一格在不同周次可能换课，左右翻周就能看到。

> 如果某个 ◇ 实验其实是别的实验班的安排，点一下课程块 → 「删除这节课」就行。

## 三个页面

| 页面 | 能做什么 |
| --- | --- |
| 今日 | 大卡片显示「正在上的课 + 还剩多少分钟 + 进度条」，下面列出接下来的课，还会预告明天；当天没课会显示「自由的今天」 |
| 课表 | 12 节次 × 周一至周五网格，可左右翻周；今天那列高亮，正在上课的格子有描边，当前时间一条红线；点空白格加课，点课程块改课 |

## 立绘壁纸（新）

设置 → **立绘壁纸** → 「选一张立绘」，把喜欢的角色图放进去，它就变成课表壁纸：

- **图片只存在这台设备上**（浏览器本地数据库 IndexedDB），不上传、也**不在 GitHub 仓库里**
- 导入时自动处理两份：**去背景版**（人物贴在奶油底上）和**保留背景版**（原图铺满整屏），用「自动去掉背景」开关随时切换对比，不用重新选图
- 可调：不透明度、模糊、位置（顶部/居中/底部）、显示范围（今日页 / 课表页分别开关）
- 课表页会自动再淡一档（垫了一层"纸张"），保证课程块和文字看得清
- 选了多张会出现在缩略图列表里，点一下就切换角色
- 去背景用的是"从四边泛洪填充"：只删掉和边缘连通、颜色接近背景的区域，所以人物身上的白衣服不会被吃掉

> 图片建议：竖版立绘、长边 1000px 以上、最好是干净背景。带背景的整图就把「自动去掉背景」关掉、大小选「铺满」。

## 装到 OPPO 手机上（Find X9 · ColorOS）

这个 App 已经做成 **PWA**（`manifest.webmanifest` + `sw.js`），只要把文件夹放到一个网址上，就能像真 App 一样装到桌面：全屏、无浏览器地址栏、**断网也能打开**，数据存在手机本地。

### 第一步：把它放到一个网址上（免费，5 分钟）

方法一（最快）：打开 <https://app.netlify.com/drop>，把这个 `我的课表` 文件夹整个拖进去，几秒后得到一个网址（形如 `https://xxx.netlify.app`），登录免费账号就能长期保留。

方法二：把这个文件夹传到 GitHub 仓库，仓库设置里开 Pages，得到 `https://用户名.github.io/仓库名/`。

> 也可以先不部署：电脑上起个本地服务（`node serve.mjs` 之类），手机连同一个 WiFi 访问电脑 IP，能看能改，但装不了图标、电脑关机就用不了。

### 第二步：手机上装到桌面

1. 用手机 **Chrome** 打开那个网址（ColorOS 自带浏览器也可以，但 Chrome 装 PWA 最稳）。
2. 如果菜单里没有「安装应用 / 添加到主屏幕」，先去开权限：
   **设置 → 应用管理 → Chrome → 权限 → 打开「创建桌面快捷方式」**，然后重开 Chrome。
3. Chrome 右上角 `⋮` → **安装应用**（或「添加到主屏幕」）→ 桌面出现「我的课表」图标，点开就是全屏 App。

装好后：状态栏颜色会跟着浅色/深色主题走；手机底部手势条留白已经处理好；页面双击不会误缩放。

### 想要真正的 APK？

用 Capacitor 把这份网页打包成 apk 也可以（需要装 Android Studio，门槛高一些）。要用这个方案告诉我，我把工程配置写好。

## 数据存在哪

存在打开它的那个浏览器里（localStorage），不上传任何服务器。
「设置 → 导出备份」会下载一个 JSON；换设备/换浏览器时用「导入备份」选它就能搬过去。
清空浏览器数据会把课表一起清掉，重要的时候先导出一份。

## 想改东西，改哪里

都在 `app.js` 顶部：

- `SLOTS`：12 节次的上课时间（上课时间从 2026-2027 学年执行的时间表，如果学校调整了改这里）
- `MY_COURSES`：我的课表数据。`day` 1=周一，`slot` 起始节，`span` 连上几节，`weeks` 是周次区间，`kind` 是理论/实验
- `PRESETS`：主题色预设
- 课程颜色在 `styles.css` 的 `--tone1` 到 `--tone6`
- 学期第一周、总周数在 App 的「设置」里改，不用动代码

## 已经支持 / 还没做

已支持：12 节次网格、多段周次（如「9周、12-13周」）、实验课标记、连堂（最多 4 节）、周次与日期自动计算、深色模式、主题色、立绘壁纸、备份导入导出、离线缓存、可装到桌面。

动效：切页会按方向左右滑入、翻周时整张课表跟着手指方向滑、课程块依次浮入、上课进度条会涨上去、编辑弹层从底部滑上滑下、提示条淡入淡出。系统里打开「减弱动态效果」时会自动关掉这些动画。

还没做（想要就告诉我）：

- 上课提醒（浏览器通知 / 系统通知）
- 冲突检测（同一时间加两门课会提示）
- 一键导出课表图片（发朋友圈那种）
- 待办作业、考试倒计时
- 自动从教务系统拉课表（需要写抓取脚本，学校系统一般要登录）
- 电脑桌面版布局
